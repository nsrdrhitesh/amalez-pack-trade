# Original image library and prompt set

All 200 bitmap assets were generated with the built-in `image_gen` tool. No competitor images were downloaded, altered or reused. WebP conversion uses GD at quality 82, preserving the source composition, with a maximum width of 1200 pixels (1600 for hero-family imagery). Original generated PNGs remain in the generator output directory; project deliverables are in `public/images/business`.

The JSON manifest at `database/content/assets.json` records each image's ID, subject, intended page, purpose, scene prompt, descriptive ALT text, dimensions, bytes and SHA-256 checksum. No local user paths or credentials are included.

## Shared art direction

Use case: product-mockup. Original premium commercial product photography for Amalez PackTrade. Exact legible brand text “Amalez PackTrade”, with PackTrade one word, printed on appropriate packaging surfaces. Distinct original graphic artwork in burnt orange, charcoal and warm ivory, with restrained sage where useful. Physical folds, seams and materials; soft studio lighting; landscape compositions. Printing must be prominent. No competitor marks, factory, machinery, certifications, fake ratings, barcodes, watermark or tiny invented copy. Images are independent illustrative design concepts, not actual product or facility documentation.

The scene field in the manifest supplies the individual subject and composition. The first 37 scenes establish five main services, 20 format guides, ten article covers, homepage and About. Service variants add structure, print detail, finish, flat layout and application views. Article variants add comparison, detail and planning scenes. Hero/About variants add collection, detail, materials and editorial compositions. This gives each service six distinct views and each article four supporting assets, plus ten homepage/About assets.

## Inspection and limitations

Every asset was inspected in contact sheets, with additional full-size checks of the hero, main services and selected structural/print details. The library depicts plausible packaging, not engineering drawings. Generated folds, substrates and print appearance must not be used to establish technical specifications or performance. Main format images and galleries carry concept captions; client-approved technical photography can replace them through Media Library without restructuring the site.

The release checker verifies 200 unique image checksums, readable image files, matching dimensions, brand-labelled ALT text, mapped page paths and a 350 KB maximum per asset. Browser preview confirms the initial images load and responsive layouts retain the existing industrial palette.
